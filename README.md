## 📖 About the Project

Cinespot is a sleek and modern web interface designed to showcase the Hot Movies of the Week.

This project was created with a strong focus on layout, visual design, responsive structure, and CSS Grid.

One of the main highlights of this project is the use of CSS Grid to create an organized and flexible layout for movie cards and different sections of the website.

This was one of my first projects where I worked extensively with CSS Grid and learned how to manage rows, columns, spacing, and responsive layouts more effectively.

## 🛠 Tech Stack

* HTML5: Semantic structure

* Responsive Design: Adapted for different screen sizes

* 🖼️ Movie card grid layout
* 📐 CSS Grid-based structure

* 📝 Clean and simple forms
